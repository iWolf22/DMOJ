# DMOJ

Over the duration of highschool I completed over 170 competitive programming problems on a competitive programming platform called [DMOJ](https://dmoj.ca).

## Overview

This repository contains all of my latest AC submissions on DMOJ. I created an open source webscrapper called [DMOJSync](./src/DMOJSync.md) to fetch, store, and commit all of the problems locally on disk in an organized fashion.
